Créditos y Aviso Legal

1. Autoría y Concepto Original

GLITCH RUN es un proyecto nacido de la creatividad de dos estudiantes. La idea original y el concepto del juego fueron creados por sh6ta_thecat y Daniel (compañero de la universidad).

El proyecto surgió como un trabajo para ganar puntos durante un curso de Java. El objetivo inicial era mezclar diferentes juegos clásicos que pudieran funcionar juntos. Tras varias deliberaciones, se decidió combinar el Dino, el Tetris y el Snake, en ese orden específico de añadidura de funcionalidades.

La primera versión del juego llevaba por nombre DISNTE (por las siglas de Dino, Snake y Tetris), y el nombre original reflejaba el orden en que se fueron integrando las mecánicas al proyecto.

2. Naturaleza del Proyecto

GLITCH RUN es un videojuego arcade independiente, desarrollado puramente con tecnologías web estándar: HTML5, CSS y JavaScript.

No representa una organización legal corporativa ni una empresa. Es el resultado del esfuerzo, la experimentación y el aprendizaje de dos desarrolladores que buscaban crear una experiencia única fusionando tres mecánicas clásicas en un solo espacio.

El código es de libre uso para fines educativos y de aprendizaje, siempre y cuando se respete el reconocimiento a sus creadores originales.

3. Sobre el Desarrollo y la Evolución

Lo que comenzó como un proyecto académico para un curso de Java evolucionó hacia una versión web completamente funcional. La idea central siempre fue mantener la esencia de cada juego, pero creando una interferencia entre ellos, como si un "glitch" los hubiera fusionado en un mismo espacio.

A lo largo del desarrollo se añadieron mecánicas como los niveles de dificultad progresiva, la manzana glitch, el medidor de sobrecarga, los combos y los efectos visuales que simulan un sistema corrupto.
